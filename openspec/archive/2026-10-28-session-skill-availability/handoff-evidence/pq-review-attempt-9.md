The user is blocked from reviewing/applying this otherwise valid native-search team selection unless an irrelevant fallback credential is supplied. Without a credential: inventory `ready`, native launch `ready`, review `ready: false` with `claude-team-install-blocked`. Supplying only a fixture credential changes review to `ready: true`, while native launch remains ready. The credential callback is unnecessarily read once per review. No network, real credential, external runner or user installation is involved. See `review-probe.json` and `review-probe.log`.

This is a newly demonstrated residual production inconsistency in the changed search-selection flow, not a claim that the unchanged review branch was first introduced by this patch. The original PQ-5 grant correction is useful and should be retained.
