Current integration pins predate the reviewed v5-capable plugin candidates, and the legacy Deck runtime imposes semantic capture and role exclusions. Managed native capture completion remains unverified. A runner change must not sever useful project memory.

Redesign and implement the integration first, then compare it with ordinary Deck without Supermemory. Provider retention is conditional on demonstrated task value. The cancelled instrumentation work is not a prerequisite.
