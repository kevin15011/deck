# Frontend aesthetic routing

## Outcome

Improve Deck's frontend aesthetic repertoire across all first-class runners. Ship a canonical standalone router, a source-audited profile catalog, compatible upstream standalone bundles, and brief canonical Lead references. Selection is instruction-level; adapters distribute resources, and plugins do not interpret user feedback.

## Acceptance

- Select by project, audience, references, desired personality and visual responsibilities, not a universal preferred style or keyword-only classification.
- Combine compatible skills with one authority per visual aspect; motion helpers can coexist with aesthetic direction.
- Consult compact profiles before loading selected skills. Do not load the entire collection.
- Preserve the current visual agreement across delegation. Material rejection replaces the direction and records rejected traits; narrow feedback keeps unaffected choices.
- Existing user/brand constraints prevail. Skill discovery is not authority to install dependencies, access services or widen effects.
- Resolve all requested sources to actual upstream names and revisions. Bundle only redistributable complete resources supported by Deck's text bundle format; disclose unavailable, unlicensed, binary-dependent and non-frontend candidates explicitly.
- All runner installation plans must expose the same canonical standalone router and bundled profiles.

## Route and boundaries

Lead owns implementation and this artifact. Two Investigate tasks independently audit upstream halves. Graph deck fast generation 2026-08-20 is stale; external skills and scripts are excluded, so current source is read directly. Current adaptive team content feeds Lead system/agent/skill surfaces. Existing package preselection changes, local Serena configuration and cache are preserved. No commit, push, new worktree, or upstream scripts are authorized by this task.

## Progress

Implemented 29 complete text-only upstream standalone bundles and the canonical router. Compact profiles distinguish visual direction, motion, native, image, chart, review and artifact responsibilities; OpenDesign/Taste are curated rather than wholesale copies. Canonical adaptive Lead and legacy session surfaces reference the router. Apply consumes the shared agreement and Quality checks it without independently replacing the aesthetic.

Claude previously omitted canonical standalone bundles; its private immutable plugin now materializes complete bundles with path/collision validation, licenses and unchanged ownership/tamper protection. Pi capability-plan reconstruction incorrectly classified nested skill `agents/openai.yaml` as a top-level agent; explicit skill metadata and anchored fallback now preserve nested support resources.

Sixteen requests were excluded with exact reasons in docs/frontend-design.md and docs/reference/frontend-design-skill-sources.json. Binary-bearing packages and the Impeccable native launcher were discarded. External full-renderer, unresolved redistribution and unsafe YAML-depth cases retain distinct reasons; upstream content and discovery policy were not rewritten to force compatibility. Supporting scripts remain passive and dependencies/credentials are not installed or supplied.
